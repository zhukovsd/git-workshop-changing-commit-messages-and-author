# Воркшоп по git - изменение сообщений коммитов и редактирование автора

Контекст:
- Всегда есть риск опечататься при написании сообщения коммитов, не всегда получается с первого раза написать полноценное и ёмкое сообщение
- При работе с разными проектами, пользователями (например, один для личного GitHub аккаунта, второй для рабочего), легко напутать и закоммитить не из-под того автора

Это создаёт потребность уметь редактировать историю коммитов. Как и самую свежую (только последний коммит), так и более раннее коммиты.

Суть задачи:
- Исправить опечатку в сообщении к коммиту `67ced6ed`
- Исправить опечатку в сообщении к последнему коммиту
- Исправить автора двух последних коммитов, вместо `Unknown Developer <unknown@developer.com>` поставить `Vladimir Kidyaev <krios2146@gmail.com>`

## Как пользоваться

- Сделайте fork данного репозитория
- Склонируйте локально
- Решите локально
